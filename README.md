# 🛒 Elite Stores Website

**Elite Stores** is a modern, responsive e-commerce website built using **HTML, CSS, and JavaScript**.
It is designed to showcase products with a clean layout, smooth animations, and interactive features.

---

## 🚀 Features

✅ Responsive and mobile-friendly design
✅ Clean and modern UI
✅ Product listing with images, price, and description
✅ Add to Cart functionality using JavaScript
✅ Search and filter products
✅ Smooth hover effects and CSS transitions
✅ Header, Product Listing, About, Contact, and Footer sections
✅ Luxury store-style theme

---

## 💻 Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)
* Google Fonts
* Font Awesome Icons

## 🛠️ How To Run

1. Clone the repository:

```
git clone https://github.com/your-username/elite-stores.git
```

2. Go inside the project folder:

```
cd elite-stores
```

3. Open the website:

Open `index.html` in your browser (or use VS Code Live Server for live preview).
